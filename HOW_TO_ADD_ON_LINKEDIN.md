# How to add this project on GitHub and LinkedIn

The project is already on GitHub:
https://github.com/saisrinivaskalari6802/regional-retail-performance-optimization

## Add the GitHub repo to your LinkedIn profile (Featured + Experience)

### A. Pin it under Featured
1. Open LinkedIn and go to your profile.
2. Scroll to **Featured**.
3. Click the **+** button.
4. Choose **Add a link**.
5. Paste: https://github.com/saisrinivaskalari6802/regional-retail-performance-optimization
6. Title: Regional Retail Performance & Campaign Effectiveness
7. Description: End-to-end SQL + Power BI case study. Star schema, campaign ROAS, 90-day retention. ~40% less manual reporting.
8. Save.

### B. Add it under Experience (Accenture / Data Analyst)
1. On your profile, go to **Experience**.
2. Click the pencil on **Data Analyst | Accenture** (or Add media).
3. Scroll to **Media** → **Add media** → **Add a link**.
4. Paste the same GitHub URL.
5. Save.

### C. Add GitHub to Contact info
1. Profile → pencil next to your intro (or **Contact info**).
2. **Website** → add https://github.com/saisrinivaskalari6802
3. Type: Personal website / Portfolio.
4. Save.

### D. Publish the post
1. LinkedIn home → **Start a post**.
2. Copy the text from `LINKEDIN.md` in this repo.
3. Paste the GitHub URL on its own line so LinkedIn generates a preview card.
4. Set visibility to **Anyone**.
5. Post.

## If you want to upload extra files yourself later
1. Open the repo link above.
2. Click **Add file** → **Upload files**.
3. Drag SQL, screenshots, or a PowerPoint.
4. Commit to **main**.
